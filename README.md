# PG-DTAN：热电压分类与消融实验

本项目实现受物理启发的双分支时频–时序注意力网络（Physics-Guided Dual-Branch Time-Frequency Temporal Attention Network，PG-DTAN）。面向单音、双音、和弦等互斥类别的离线分类。目前没有真实实验数据或识别效果结论。

## 架构与设计理由

```text
同一段电压 → 播放前基线校正 → 使用训练集统一尺度缩放
    ├─ STFT → 2D CNN → 仅沿频率维平均 → 时频特征序列
    └─ 电压＋平滑差分 → 1D CNN → 时间网格采样 → Bi-LSTM
                       ↓
               同一时间网格上的特征拼接
                       ↓
             线性投影 → LayerNorm → GELU
                       ↓
              时间注意力池化 → Dropout → 分类
```

- STFT 是短时傅里叶变换，CNN 是卷积神经网络，Bi-LSTM 是双向长短期记忆网络。STFT 的频率轴描述电压变化频率，不能默认解释为声音基频或谐波。
- STFT 使用中心对齐和常数零填充，中心位置为 `0, hop_length, 2*hop_length, ...`，丢弃中心超出原信号范围的帧。波形卷积保持长度，在这些相同位置采样后送入 Bi-LSTM。二维卷积仅在频率轴池化，保留时间轴。边界特征受填充影响，注意力权重不能单独证明物理机制。
- 差分通道先用复制边界的滑动平均平滑，再计算向后差分，首点置零。通道实际为 `ΔV`，等于 `dV/dt` 的离散估计除以采样率，避免固定采样率带来数值放大；它不是直接测得的能量输入速率。所有数据必须使用相同采样率，平滑只用于差分通道。
- 基线校正减去每段前 `baseline_samples` 点的均值。这些点必须是播放前静音记录。统一尺度为基线校正后训练集所有点的均方根，验证集与测试集复用该尺度，不对每段单独归一化。
- 模型返回未经 Softmax 的 logits，训练使用交叉熵；预测阶段转换为类别概率。Bi-LSTM 使用未来信息，仅适用于完整片段离线分类。
- 所有分支使用浅层卷积，默认卷积通道为 16/32、单层双向 LSTM 每方向 32、融合维度 64。这些是可运行的起始值，尚未根据器件数据优化。

## 环境

建议使用 Python 3.10 或更高版本。在本目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python smoke_check.py
```

`smoke_check.py` 使用临时生成的随机数据检查六种配置的前向和反向传播、注意力归一化、时间坐标、批次泄漏拦截、训练集尺度隔离、一轮训练、权重恢复和预测。随机数据上的分数没有科学意义。当前在 Python 3.12、PyTorch 2.15.0、NumPy 2.5.4 的 CPU 环境验证。

## 数据约定

每个 `.npy` 文件保存一个一维实数电压数组，单位一致。所有样本等长、同采样率、播放起点一致，保留静音基线与需要分析的恢复阶段。预先统一时间窗；本程序不静默截断、补齐或重采样。

使用 UTF-8 CSV 清单，路径相对清单所在目录解析：

```csv
path,label,batch_id,trial_id,split
voltages/day1_C3_01.npy,C3,day1,day1_C3_01,train
voltages/day1_E3_01.npy,E3,day1,day1_E3_01,train
voltages/day2_C3_01.npy,C3,day2,day2_C3_01,val
voltages/day2_E3_01.npy,E3,day2,day2_E3_01,val
voltages/day3_C3_01.npy,C3,day3,day3_C3_01,test
voltages/day3_E3_01.npy,E3,day3,day3_E3_01,test
```

上面仅演示格式，不是足够训练的数据量。标签可用 `C3_E3`、`C_major` 等自定义名称。`trial_id` 必须全局唯一标识一次原始试验；同一次记录切出的多段共享该 ID。`batch_id` 标识独立采集批次，同一批次必须整体进入一个集合。程序也会拒绝重复文件路径，以及训练集没有的验证/测试类别，并要求各集合覆盖所有类别。

跨文件复制的重复数据不能仅通过路径检查识别，准备数据时仍须人工核对来源。批次编号必须真实反映独立采集过程，不能为绕过检查而重新命名。

## 训练与消融

下列数值仅演示命令格式，不是论文或你们器件的采集参数。请用实际采样率、静音基线点数和适合热响应时间尺度的 STFT 窗口替换。

```bash
.venv/bin/python train.py \
  --manifest data/manifest.csv \
  --sample-rate 1000 \
  --baseline-samples 1000 \
  --n-fft 256 --hop-length 64 \
  --variant full --seeds 42 43 44 \
  --epochs 50 --batch-size 16 \
  --output runs/full_run
```

用 `--variant all` 顺序运行以下六种配置，或单独指定其中一种：

| 配置 | 相对完整模型的变化 |
| --- | --- |
| `temporal_only` | 仅时序分支，保留差分、Bi-LSTM、注意力 |
| `spectral_only` | 仅时频分支，保留注意力 |
| `no_derivative` | 时序分支仅输入电压 |
| `no_lstm` | 移除 Bi-LSTM，保留一维卷积 |
| `mean_pool` | 用时间平均池化替换注意力池化 |
| `full` | 完整模型 |

各配置使用相同清单、训练集尺度、随机种子列表、批量大小、训练轮数和优化器设置。AdamW 的默认学习率为 0.001，权重衰减为 0.01；梯度范数裁剪为 1。每轮仅评估验证集，按验证集宏平均 F1 选择权重，训练结束后评估测试集。默认 CPU，可用 `--device cuda`；CUDA 确定性运行可能需要在启动前设置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`。不同硬件和库版本不保证完全一致。

不增加隐式增强、类别权重或自动调参，方便首先建立受控比较。若以后添加这些选项，应对各配置保持一致。消融会自然改变参数量，不能把性能变化全部归因于单个机制；输出会记录参数量。建议另外补充简单统计特征分类器作为传统基线。

## 输出与预测

输出目录必须不存在，避免覆盖历史实验。文件包括：

- `manifest_snapshot.json`：本次样本路径、类别、批次及集合划分。
- `<variant>/seed_<seed>/best.pt`：模型参数、类别映射、预处理尺度、样本长度、模型与训练配置。
- `<variant>/seed_<seed>/metrics.json`：每轮记录、最佳轮次、验证/测试准确率、宏平均 F1、各类支持数及混淆矩阵。矩阵行为真实类别，列为预测类别。
- `summary.json`：各配置跨种子的测试指标、均值与样本标准差；单个种子时标准差为 `null`。

宏平均 F1 对每类分别计算 F1 后等权平均，适合与准确率一起报告。随机种子波动不等于跨独立采集批次的泛化不确定性；后续可用更多预先确定的批次划分重复比较。不要根据测试集结果反复选模型和调参；若需要比较后继续开发，应保留额外的最终独立测试数据。

```bash
.venv/bin/python predict.py \
  --checkpoint runs/full_run/full/seed_42/best.pt \
  --voltage data/voltages/new_trial.npy
```

预测使用训练时预处理参数，输出类别概率、时间网格及注意力权重。输入必须与训练时的采样率、单位、播放对齐和窗口长度一致；`.npy` 不含采样率元数据，该项需自行核对。只加载自己生成或可信来源的权重。

本实现未引入热传导方程损失，也不宣称实现热惯性补偿、音源分离或弱音符恢复。此类结论需要独立实验支持。若任务改为同时判断多个音符是否存在，需要改为多标签输出、相应损失和评价方法。
